“浏览器”标签页会在对话旁边嵌入你选择的页面——通常是你正在开发的项目的开发服务器。页面的运行方式与在普通浏览器标签页中完全相同：直接联网、实时重载、Service Worker 都可用。TwiCC 不会代理它，也不会将它放入沙箱。

**如果想让智能体帮你设置开发服务器，**请让它参考此页面：
<https://github.com/twidi/twicc/blob/main/frontend/public/help/browser-tab.md>。
其中包含所需的一切：框架嵌入、Cookie 以及 Companion 脚本。智能体还需要知道你访问 TwiCC 的地址：标签页中的设置提示提供了 **将说明添加到消息** 和 **复制给智能体的说明**，这是一段现成的提示词，包含此页面、该地址以及 Companion 代码片段。

### 打开页面

在地址栏中输入任意 URL。**主页** 按钮会跳转到已保存的默认 URL；使用 **收藏** 菜单可将当前 URL 保存为项目（或其某个工作区）的默认 URL——之后该标签页会直接打开它。每个会话还会记住你上次所在的 URL。

### 嵌入的限制

有些页面无法被嵌入：

- 拒绝被嵌入框架的网站（大多数公共网站都是如此）会显示警告——请改用 **在新浏览器标签页中打开**。
- 当 TwiCC 本身通过 `https` 提供服务时，普通的 `http://` 页面会被浏览器阻止（混合内容）。

本地开发服务器才是最合适的用途；这个标签页正是为此而设计的。

### 登录与存储

嵌入的页面能否保持登录状态，取决于你的开发服务器与 TwiCC 的相对位置。

**同一主机**——TwiCC 和你的应用都在 `localhost` 上，端口任意。无需任何操作：页面共享它在普通标签页中使用的完全相同的 Cookie 和存储，因此你在那里完成的登录同样有效。这里端口无关紧要——`localhost:5173` 和 `localhost:3000` 被视为同一站点。

**不同域名**——例如 TwiCC 在一个隧道上，你的应用在另一个隧道上。浏览器会隔离嵌入的页面，因此你一开始处于未登录状态，并且需要一些 **仅限开发环境** 的设置：

- **允许框架嵌入**——许多框架默认通过 `X-Frame-Options` / `frame-ancestors` 禁止嵌入（Django、Rails…）；请在开发环境中放宽限制。
- **Cookie**——将会话 Cookie 设置为 `SameSite=None; Secure`。`Secure` 在 `https` 和 `http://localhost` 下有效，但在纯 http 的局域网 IP 下无效。
- 然后 **在标签页内登录一次**。嵌入的页面拥有自己独立的私有 Cookie/存储区域，在重新加载后仍会保留。`localStorage` 和 `IndexedDB` 无需任何设置——同样的隔离，直接可用。

请把这些设置放在开发标志之后——你不会希望在生产环境中使用 `SameSite=None` 或开放框架嵌入。

### Companion 脚本

嵌入的页面对 TwiCC 来说是一个黑盒：在页面内点击的链接不可见，因此后退 / 前进只能跟踪在工具栏中输入的 URL。TwiCC 提供了一个 **Companion 脚本**，将它添加到你的开发页面即可消除这一限制并解锁更丰富的功能：

- 真实的导航跟踪——后退 / 前进 / 重新加载会驱动页面自身的历史记录，页面内（SPA）导航会更新地址栏；
- **元素选择**——不必描述“标题栏中的第三个按钮”并寄希望于智能体能找到它，只需用工具栏中的 **鼠标指针** 按钮开启该模式，在页面上直接点击元素，然后点击 **评论** 按钮：会打开一个组件，你可以添加可选的备注（并附上该元素的截图），然后将所有内容粘贴到聊天输入框——这是对元素精确且便于定位代码的描述（标签、id、class——智能体能在源码中找到的信息），并附有你的评论。非常适合“把这个放大”或“这个标签写错了”之类的需求；
- **页面错误**——未捕获的异常和 `console.error` 调用会被收集，在工具栏中计数，一键即可添加到你的消息。

该代码片段是一个 `<script>` 标签，指向 TwiCC 主机上的 `/_twicc/browser-companion.js`：

```html
<script src="https://your-twicc-host/_twicc/browser-companion.js" defer></script>
```

请将它添加到页面的 `<html>` **head 中，越早越好**——最好作为 `<head>` 中的第一个标签，位于其他所有脚本之前。它加载得越早，就越早开始捕获导航和错误（它使用 `defer`，因此永远不会阻塞你的页面）。它对页面本身不可见，在页面于 TwiCC 之外运行时什么也不做，因此可以放心地保留在开发模板中。

你不必手动输入 URL：当嵌入的页面没有 Companion 时，标签页中的横幅（以及 **插头** 按钮）会提供这段代码片段——已填好正确的主机——可直接复制。如果你从另一台机器访问 TwiCC，请配置 [外部地址](help/external-url)，使复制的代码片段指向你的浏览器能访问的地址。

**插头** 按钮显示 Companion 的状态：已连接时为品牌色，缺少脚本时为红色，检测中为暗色。点击它会打开此帮助页面。

### 响应式模式

**手机** 按钮会为页面提供精确的设备尺寸视口：选择一个预设（或输入宽 × 高）、交换宽高，或拖动框架周围的手柄。页面会完全按照该尺寸窗口重新排版。无需 Companion。

### 其他

- **全屏** 会展开整个标签页，包括工具栏。
- **在新浏览器标签页中打开** 会将当前 URL 交给你真正的浏览器。
- 错误、选择和评论总是进入你正在编写的消息——没有你的操作，不会向智能体发送任何内容。
