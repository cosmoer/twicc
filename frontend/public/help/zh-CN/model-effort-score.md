模型选择器是一个 **矩阵**：每个模型一行，每个推理强度一列。每个可选单元格都显示一个 **0 到 100 的分数**：表示该模型在该推理强度下，与你通过矩阵下方控件描述的任务的匹配程度。分数越高越好。淡色的 **?** 表示该组合没有可用数据。

矩阵带有几种视觉提示：

- 分数越高，单元格的 **背景** 颜色越深；
- **对勾** 标记当前选中的单元格，小 **圆点** 标记默认单元格；
- **圆环** 突出显示每个提供方的最高分——默认提供方为实线，同时显示多个提供方时，其他提供方为虚线。

## 数据来源

分数基于 **[Artificial Analysis](https://artificialanalysis.ai/)** 发布的评测结果计算，这是一个独立的基准测试网站。它在多项评测上测量每个模型在每种推理强度下的表现，并记录每项任务的 **成本** 和 **时间**。

TwiCC 内置了这些结果在 **2026-11-10** 的快照，基于 Intelligence Index 5.0.1 版本。它不会自动更新。

## 控件

- **任务类型**——你将要进行的工作类型（见下文）。*通用* 使用 Artificial Analysis 的综合 Intelligence Index。
- **任务难度**——模型需要具备多强的能力。困难任务向上调，简单任务向下调。
- **偏好**——**成本** 优先选择更便宜的组合，**速度** 优先选择更快的组合。
- **自动选择最佳**——每当控件变化时，自动为你选中得分最高的单元格，效果与你手动点击完全相同。同时显示多个提供方时，**仅默认提供方** 会将选择限制在你的默认提供方内。
- 每次打开或关闭选择器、设置面板或预设表单时，**自动选择最佳** 和 **显示旧模型** 都会关闭。

## 分数的含义

难度会在任务类型的能力量表上设定一个 **目标水平**。**达到或超过** 目标的组合可以胜任工作：其中更便宜（或更快）的胜出。略 **低于** 目标的组合会扣掉一些分数；远低于目标的组合会扣分太多，即使价格低也无法挽回。

- **100** 是该任务的最佳组合。
- **50** 表示“差一个倍数”：成本（或时间）是最佳组合的两倍，或者低于目标的程度相当于此。
- 更远的组合会保留 **很小但非零** 的分数。其中几个可能显示相同的数字：**圆环** 仍会标出每个提供方的最佳组合，因此你可以选出单个提供方中最好的那个。
- 分数会将 **所有已启用的提供方** 放在一起比较，因此你可以在 Claude Code 和 Codex 之间进行选择。已禁用的提供方、已退役或已禁用的模型，以及模型不支持的推理强度都不计入。
- 旧模型只有在开启 **显示旧模型** 时才计入。否则分数只比较最新模型，因此 100 分总是出现在可见单元格上。你已选中的旧模型会保持可见，并与最新模型一起评分（最高 100），但永远不会获得圆环，也不会被 **自动选择最佳** 选中。
- Intelligence Index 5.0.1 版本只测量了少数旧模型，而且通常只测量其最高推理强度。它们的其他单元格显示 **?**。

## 任务类型

| 任务类型 | 依据 |
|---|---|
| 通用 | Intelligence Index（Artificial Analysis 的综合分数）；成本和时间来自 Terminal-Bench 4.0 |
| 编程与终端 | Terminal-Bench 4.0（终端中的智能体编程）、FrontierCode 2.0（编程） |
| 办公与知识工作 | AA-Briefcase（知识工作交付物）、GDP.pdf（文档推理） |
| 自动化与工具 | AutomationBench-AA（使用工具的 SaaS 工作流） |
| 科学与推理 | HLE Diamond（高难度推理）、CritPt v2 Hard（物理）、Terminal-Bench-Science（终端中的科学工作） |
| 事实知识 | AA-Omniscience（知识与幻觉） |

对于基于多项评测的类型，能力取它们的平均值（每项均为 0–100 量表），成本和时间也是如此。

## 实现细节（供好奇者参考）

- 滑块将 **0** 映射到所选任务类型中最弱的组合，将 **100** 映射到最强的组合，曲线在开始阶段上升很快：滑块的中间位置就已经要求一个能力较强的模型。
- **超过目标不加罚**：超过目标的组合只需为其成本（或时间）付出代价。
- 低于目标 **2 个 Intelligence Index 分** 的影响相当于付出两倍的价格；其他任务类型会按各自的范围进行缩放。惩罚随差距的 **4 次方** 增长：低于目标 4 分的影响相当于付出 2¹⁶ 倍的价格。
- 分数在第一个倍数内从 100 降到 50，之后下降得越来越慢，因此永远不会降到 0。
- 成本和时间按 **对数** 尺度比较：重要的是比值（从 $1 到 $2 与从 $10 到 $20 同等看待）。
- 时间是 Artificial Analysis 的每任务时间：生成回答所花的时间，不含启动延迟。
