项目是智能体会话运行所在的 **工作目录**——每个文件夹对应一个项目。TwiCC 会为每个包含会话的文件夹自动创建项目，包括你在 TwiCC **之外** 使用 Claude Code 或 Codex 运行的会话。你也可以让 TwiCC 指向某个文件夹，自己添加项目。

### TwiCC 在项目下保存什么

在该文件夹中运行的每个会话都会归入该项目——这样你就可以按工作发生的位置找到它。

### 打开项目

在主页上点击项目，或在侧边栏顶部的项目选择器中点击（即使是已选中的项目），即可打开项目的 **主页**。在会话内部，点击标题栏中的项目名称即可返回项目。

要重命名项目或更改其设置，请打开其 **⋮** 菜单（在主页或项目选择器中）并选择 **编辑**。

### 个性化

为项目设置 **名称** 和 **颜色**，并设置 **项目默认值**（提供方、智能体设置、默认布局），在此项目中新建的每个会话都会以这些值为初始设置。

命名还会影响主页列表的排序：**已命名** 的项目以卡片形式显示在顶部，便于快速访问重要项目；**未命名** 的项目列在下方，按路径分组为文件夹树。

### 组织

将相关项目归入一个 [工作区](help/workspaces)。Git 仓库的 [工作树](help/worktrees) 会显示为独立的项目，并链接回该仓库——因此打开一个项目时也会列出其工作树中的会话，并带有徽标区分父项目会话和工作树会话。

### 归档

项目已经完成？将其 **归档**——它会从列表中隐藏，但不会删除任何内容，其会话仍可搜索。可以在其编辑对话框中归档，也可以通过侧边栏顶部项目选择器中的 **⋮** 菜单归档。要再次查看已归档的项目，请在主页的“项目”部分勾选 **显示已归档**；在那里你可以 **取消归档** 其中任意项目。
